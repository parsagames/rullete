1. Extract this ZIP.
2. Upload all contents to the root of a GitHub repository.
3. Keep the `.github/workflows/release-apk.yml` file.
4. Add these Repository Secrets: RELEASE_KEYSTORE_B64, RELEASE_STORE_PASSWORD, RELEASE_KEY_ALIAS, RELEASE_KEY_PASSWORD.
5. Open Actions → Build Release APK → Run workflow.
6. Download the `roulette-release-apk` artifact.
